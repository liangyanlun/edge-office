# 弹窗关闭与 PC 存储位置修复

## 使用方式

Windows preview.5 安装向导始终显示软件安装位置选择页，下一页单独选择模型保存位置。软件目录与模型目录可以位于不同磁盘；模型文件由应用首次下载。安装模型位置写入当前用户 HKCU Software/EdgeOffice ModelsDirectory。

应用内打开“你的工作区 → 模型与下载”，每个未下载的模型都有“选择下载位置…”按钮，使用 Windows 原生文件夹选择器。应用会在选定文件夹中建立对应模型子目录，显示完整实际下载位置；选择结果保存在用户数据目录的 desktop_storage.json，重启后继续使用。取消选择不会更改配置；下载进行中、模型已安装或被占用时不会改动下载位置。此修复不迁移已有模型文件。

设置弹窗、材料选择/结果编辑等提示弹窗的标题与右上角关闭按钮位于正文滚动区域外，正文独立滚动。引导也增加固定关闭按钮，点击即关闭，不等待偏好保存请求。

## 验证

Python 原生存储专项6项、全 tests_py 77项通过；npm test 14项通过。真实 Edge 浏览器在1440×920和390×667窗口下滚动设置和长提示正文，关闭按钮前后Y坐标保持不变且可点击；引导可关闭。报告 outputs/dialog-storage-smoke-20261011/report.json。原生目录选择/取消、中文与空格路径、重启记忆、真实下载安装目标、并发/已下载拒绝，以及HTTP路径注入拒绝均通过隔离临时目录测试。

HTTP 下载接口继续只接受固定模型ID和来源，不接受任意链接或路径。文件夹授权来自桌面原生对话框；桥接只允许本应用窗口页面调用。

preview.5 包在 .release-work/ui-storage-preview5-20261011 独立构建，避免覆盖已有构建产物；安装包最终SHA与路径由构建收据记录。不发布到外部仓库。
