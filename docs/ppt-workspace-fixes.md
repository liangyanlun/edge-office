# PPT 工作副本与手机弹窗修复（2026-10-13）

源码 `0.2.0-dev.20261013` 纳入 GitHub main 发布；Windows 试用包 `v0.2.0-preview.6` 与 Android 调试包 `0.2.0-dev.20261013` / versionCode 11 仍为本机构建。校验凭据、截图另保存在本机 outputs，不上传个人测试输出；源码上传不等于安装包 Release 发布或公开站点部署。

## 用户流程

导入 PPTX → 选择页面 → 输入修改要求或上传替换图片 → 生成并核对修改前后预览 → 应用修改并自动保存 → 直接继续编辑。应用后保留选中页、清空已完成的要求。历史与原件默认折叠；只有带走文件时才需要「导出 PPTX」。撤销不会覆盖原件，而是恢复为当前工作副本并记录历史。

这是简化界面步骤，不是取消安全确认。服务器/手机只发布已经预览验证的副本，不重新运行模型；确认请求只含 patch ID。过期版本、非法 ID、任意路径、操作篡改仍拒绝。首版仅替换/克隆/删除段落、替换/删除图片，不新增页、表格、图表、SmartArt 或动画。

## 预览与窗口

- 电脑优先在独立、隐藏 worker 中使用 PowerPoint COM 导出；路径通过环境变量传递，避免 PowerShell 参数解析错误。禁止宏，原件只读。缺少 Office 时尝试隔离 LibreOffice，再降级到明确标注的结构预览。
- 结构预览使用中文字体、段落字号和原始幻灯片比例，不再统一压成 16:9 或把中文绘成重复方块。旧预览缓存按渲染修订号自动更新。复杂母版、图表等仍不能宣称高保真。
- PowerShell/LibreOffice 子进程使用隐藏窗口、无控制台创建标志；用户主动点「打开」是例外，仍会启动对应文档应用。
- 手机在 IndexedDB 中保留 PPTX 原件、工作副本、图片与受限计划，离线 SVG 结构预览。严格解析字面量调用，无 eval；执行后重新解析并验证非目标页未变化。只允许后端生成的 asset ID，不接受模型指定本机路径。
- 引导、设置、长提示窗口的头部不参加正文滚动；× 至少 44×44，支持手机安全区和横屏。不是在长内容末尾追加一个关闭按钮。

## 目录与兼容性

Windows 安装向导分别允许选择软件目录和默认模型目录；已安装 App 的模型中心通过原生目录选择器指定尚未下载的模型位置，普通网页不能传入任意本地路径。已经下载/加载的模型不自动搬家，原位置和个人材料保持不变。

Android 仅 arm64 调试构建；模型下载仍需联网，下载完成后推理和 PPT 处理无需网络。建议 PPT 使用 4B；0.8B 保留低能力提示，不保证复杂修改成功。4B 的模型生成质量与真机内存/速度仍需独立验收，不能用固定样例 planner 的界面测试替代。

## 验证边界

Python / Node 单元与回归测试覆盖五类操作、原件保留、重开、非目标页、非法输入、过期/篡改确认、目录防护与隐藏 worker。另有实际 PowerPoint 中文/空格路径导出检查，以及 python-pptx → 手机 executor → python-pptx 重开的跨运行时检查。

浏览器 390×640 验证引导及设置正文滚动，× 坐标不变；844×390 横屏可关闭。手机界面链路使用隔离存储与明确标记的测试 planner，验证导入、预览、确认自动保存、撤销；不读取用户材料。截图位于 `outputs/ppt-workspace-fixes-20261013/`。尚未完成 Android 真机、正式签名、100 份真实 PPTX 或云站点部署验收。
